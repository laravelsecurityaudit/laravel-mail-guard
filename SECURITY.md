# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's "Report a vulnerability" tab on this
repository (Security then Advisories), or email
artiushenkoandrei@gmail.com. Include the affected version, a
description of the issue, and steps to reproduce. We aim to acknowledge a
report within 3 business days and to ship a fix or mitigation as quickly as
the severity warrants.

## Supported versions

Security fixes target the latest released minor of `laravelsecurityaudit/laravel-mail-guard`. Once a stable
1.0 line exists, the previous minor is supported for security fixes for 6
months after a new minor ships.

## Scope

`laravelsecurityaudit/laravel-mail-guard` is defensive tooling. Reports of detection or enforcement bypasses,
and of any way to tamper with stored records or receipts, are in scope and
welcome.
